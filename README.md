## 🚀 Projects

### 🖥️ Hayek (Hermes Agent): AI Infrastructure

**Completed.**
Configured and secured a Contabo VPS, deployed Hermes in an isolated Docker environment, and connected it to OpenAI and Telegram. The setup includes SSH access, firewall protection, Fail2ban, backups, and recovery procedures.

### 📊 Economic & Financial Intelligence Agent

**In progress.**
Converting _Hayek_ into a specialized agent for executive economic briefings, global market and macro monitoring, alerts, and analysis of implications for the Dominican Republic.

### 📈 Financial Market Data Service

Designing an **OpenBB**-based service for downloading financial market data from free sources, with flexible options for assets, providers, intervals, output formats, and optional scheduling.

### 📉 GDP Nowcasting — Dominican Republic

**Work in progress.**
Developing and evaluating a real-time GDP nowcasting framework for the Dominican Republic, building on the IDB methodology previously applied to Belize and El Salvador. The project combines high-frequency indicators, machine-learning models, reproducible R workflows, validation, and continuous updating as new data become available.

### 🏠 Poverty Nowcasting — Dominican Republic

**Work in progress.**
Evaluating and extending a microsimulation-based poverty nowcasting framework for the Dominican Republic. The project links macroeconomic and labor-market conditions to household income and poverty estimates, and explores alternative targeting scenarios for social transfers, alongside a reproducible R implementation and an interactive Shiny tool.
